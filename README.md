# Nordiqzenz

Statisk varumärkessajt med utfällbara kollektioner. Varje produktserie länkar till en sökning hos Teknikproffset. Produktbilderna ligger lokalt i `assets`.

## Publicera med GitHub Pages

Lägg ZIP-filens innehåll i repots rot på `main`, inklusive `.nojekyll`. Välj **Settings → Pages → Deploy from a branch → main → /(root)**.

Öppna `index.html` för lokal förhandsvisning. Produktserier ändras i `index.html`. Typografi och varumärkesfärgen finns i `style.css`.
